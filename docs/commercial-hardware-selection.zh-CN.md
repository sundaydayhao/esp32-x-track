# X-Track 商业版本主控与屏幕选型建议

整理日期：2026-09-12  
适用场景：户外骑行、离线地图、GNSS 定位、骑行数据与 GPX 轨迹记录。  
文档性质：选型建议与样机验证依据，尚未锁定量产 BOM。

**推荐结论**

对于以离线地图为主要卖点的骑行产品，立创实战派标准版的 2.0 英寸屏幕偏小。建议首款商业版本评估 **3.2～3.5 英寸屏幕，优先采用 3.5 英寸、320×480 分辨率**。

按当前功能范围，优先方案是 **ESP32-S3＋16 MB Flash＋8 MB PSRAM＋3.5 英寸户外可读屏幕**。主控可以沿用，屏幕、电源、按键和结构需要围绕产品重新设计。

实战派适合作为软件与功能验证平台。当前固件已经通过编译和主机核心测试，但尚未完成实机验证；这不能直接证明量产性能、户外可读性或续航。新屏幕也需要单独适配和实测。[当前工程说明](../software/esp-idf/README.md)、[已有验证记录](../software/esp-idf/VALIDATION.md)

**屏幕尺寸的判断依据**

地图需要同时显示道路、路线、当前位置和必要的骑行数据。2.0 英寸屏幕可以用于开发验证，但在车把安装距离、振动和短时间扫视条件下，显示空间与触摸区域都比较紧张。

商业产品并非越大越好。Garmin 官方对比中，Edge 540/840 使用 2.6 英寸屏幕，Edge 1040/1050 使用 3.5 英寸，分别体现紧凑与大屏的取舍。这里仅作为尺寸参考，不据此推断本项目的性能或续航。[Garmin 官方对比](https://www.garmin.com.my/minisite/cycling/)

| 尺寸方向 | 对本项目的建议 | 主要取舍 |
|---|---|---|
| 2.0 英寸 | 保留为现有功能验证平台 | 体积小，地图与触摸空间有限 |
| 约 2.7～3.2 英寸 | 紧凑、长续航方向的候选 | 需验证字体、地图信息量和户外阅读距离 |
| **3.5 英寸** | **地图为主要卖点时优先评估** | 显示空间更充足，整机尺寸和背光耗电也需控制 |

建议先试做竖屏布局：320 像素宽、480 像素高，为行进方向前方的地图留出更多显示空间。横屏布局则为 480×320，最终方向由实物安装与操作测试决定。

**主控与屏幕组合**

| 产品方向 | 主控建议 | 屏幕建议 | 软件与硬件影响 |
|---|---|---|---|
| **首款产品：离线底图、轨迹、骑行数据** | **ESP32-S3；16 MB Flash＋8 MB PSRAM** | **3.5 英寸、320×480；户外 IPS 或合适的半透反射屏** | 现有 ESP-IDF 5.5 代码复用最多，优先验证此方案 |
| 更复杂的地图界面、更高分辨率 | ESP32-P4；无线功能按需增加 ESP32-C6 | 3.5 英寸、480×800；兼容的 MIPI DSI 屏 | 显示性能余量更大，需要重新设计板级、电源和显示驱动 |
| 长续航是核心卖点 | STM32U5A9；无线功能按需增加 | 约 2.7～3.2 英寸反射式/MIP 屏 | 需要离开 ESP-IDF，移植底层并重新设计低功耗策略 |

ESP32-P4 提供 MIPI DSI 和图像处理外设，但没有内置 Wi-Fi/蓝牙；需要无线功能时，可配合 ESP32-C6 等器件。P4 是性能升级候选，不能默认比 S3 更省电，也不能保证更换芯片后地图操作自动流畅。[P4 数据手册](https://documentation.espressif.com/esp32-p4_datasheet_en.html)、[无线扩展说明](https://docs.espressif.com/projects/esp-idf/en/release-v6.0/esp32p4/get-started/index.html)

STM32U5A9 属于低功耗 MCU，具有图形加速能力和较大的片上 SRAM，适合加入长续航方向的比较。不过，整机续航仍取决于屏幕、GNSS、无线工作占空比和电源设计。反射式/MIP 屏幕的颜色、分辨率、接口和供应情况也必须按具体型号确认。[STM32U599/5A9 官方资料](https://www.st.com/en/microcontrollers-microprocessors/stm32u599-5a9.html)

**为什么首款产品仍优先考虑 ESP32-S3**

当前工程使用预制地图瓦片，核心任务是读卡、显示地图、更新位置、计算骑行数据和记录 GPX。这个范围值得先在 S3 上验证，以保留现有代码和开发经验。

320×480 分辨率下，两帧 RGB565 缓冲占用：

```text
320 × 480 × 2 字节/像素 × 2 帧
= 614,400 字节
= 600 KiB
```

这说明两帧显示缓冲本身可以纳入 8 MB PSRAM 的预算，但不代表整套应用一定流畅。还需要统计地图缓存、图片解码、任务栈和其他堆分配，并测量读卡、绘制、传输同时工作时的延迟。

若产品后续增加复杂矢量地图、频繁整图旋转、地址搜索和离线算路，应重新评估地图软件架构和主控，而不是仅增加屏幕分辨率。

**屏幕采购与打样规格**

| 项目 | 建议要求 | 验证重点 |
|---|---|---|
| 尺寸/分辨率 | 优先 3.5 英寸、320×480 | 实际可视区、外形尺寸、车把安装距离下的文字和道路识别 |
| 显示技术 | 高亮 IPS；同时比较半透反射方案 | 正午阳光、侧光、阴影和夜间效果 |
| 亮度 | 对透射式 IPS，可把 **800～1000 nit 作为高亮模式选型目标** | 明确裸屏还是贴合后的亮度，以及对应背光电流；不是固定达标门槛 |
| 盖板与贴合 | 评估低反射盖板和全贴合 | 反光、对比度、戴偏光眼镜时是否出现暗屏或色偏 |
| 背光控制 | 支持亮度调节，必要时加入环境光调节 | 日常平均耗电，不能只测最高亮度 |
| 显示接口 | S3 的新 PCB 优先评估 8080 并口；样机也可先用 SPI | 核对屏幕实际引出的接口和初始化方式，不仅看控制器支持列表 |
| 触摸与按键 | 触摸用于地图操作，保留录制、返回等实体按键 | 雨水、手套和骑行振动下能否完成核心操作 |
| 供货与资料 | 完整规格书、初始化参数、背光参数、接口定义 | 样品与批量一致性、供货周期、替代料和变更通知 |

ESP-IDF 5.5 提供 S3 的 I80/8080 显示驱动。并口方案需要在量产 PCB 上重新分配 GPIO，不能直接通过实战派仅引出 GPIO10/11 的多功能口完成替换。[S3 I80 官方说明](https://docs.espressif.com/projects/esp-idf/en/v5.5/esp32s3/api-reference/peripherals/lcd/i80_lcd.html)

高亮并不等同于户外可读。盖板反射、贴合、对比度、安装角度与偏光眼镜都会影响实际体验。屏幕上的“IPS”或驱动芯片型号也不能代替这些验证。

样机阶段可以用 **ST7796S＋FT6336 系列触摸的 3.5 英寸模块**验证尺寸和界面。例如微雪有 320×480、SPI 显示＋I2C 触摸的模块。它是打样参考，不是已经通过本项目户外验证的量产料号；不能假定该模块具有 800～1000 nit 亮度或引出了 8080 并口。[微雪模块资料](https://www.waveshare.com/wiki/3.5inch_Capacitive_Touch_LCD)

P4 的 MIPI 方案也要核对屏幕的 lane 数、视频/命令模式、供电、初始化和驱动支持，不能只依据“MIPI”名称判断兼容。[IDF 5.5 MIPI DSI 说明](https://docs.espressif.com/projects/esp-idf/en/v5.5/esp32p4/api-reference/peripherals/lcd/dsi_lcd.html)

**续航预算示例**

以下是用于选型的假设，不是本产品已测得的续航：

- 电池标称容量：2500 mAh。
- 电池标称电压：3.7 V。
- 按标称能量的 85% 作为可用能量预算。
- 目标续航：20 小时。

```text
标称能量 = 2.5 Ah × 3.7 V = 9.25 Wh
预算可用能量 = 9.25 Wh × 85% = 7.8625 Wh
整机平均功耗上限 = 7.8625 Wh ÷ 20 h ≈ 0.39 W
```

约 0.39 W 的预算需要覆盖显示背光、GNSS、主控、存储、无线和电源损耗。是否能达到，需要通过真实样机测量。因此，如果全天常亮续航是核心卖点，应尽早比较半透反射屏或 MIP 屏，而不是先把高亮 IPS 和电池尺寸固定下来。

样机应记录不同亮度、地图操作、录制和无线同步状态下的电流，再根据预计使用时间占比计算平均功耗。还应验证低温、老化和电源转换效率对可用能量的影响。

**ESP32-P4 的版本注意事项**

若最终选择 P4，新设计应核对具体芯片修订版，优先依据官方 v3.x 资料设计，不能照搬早期开发板的供电和引脚处理。

针对 v3.2，官方提供了芯片升级和兼容说明。当前工程使用的 IDF 5.5.5 已达到官方针对 v3.2 外部 32 kHz 晶振场景提出的最低版本要求，但这不意味着现有 S3 固件可以直接运行在 P4 上，仍需重新配置、编译和验证板级适配。[P4 升级说明](https://documentation.espressif.com/en/PCN202600801_ESP32-P4_Chip_Revision_v3.2_Upgrade_Chip_Revision_v1.3_Demand_Collection_and_EOL_Plan_Description.html)、[v3.2 兼容公告](https://documentation.espressif.com/AR2026-004_Compatibility_Advisory_for_ESP32-P4_Chip_Revision_v3.2_CN.html)

**锁定量产型号前的验证计划**

| 步骤 | 执行内容 | 用于决定什么 |
|---|---|---|
| 1. 明确产品约束 | 确定目标售价、常亮续航、整机尺寸/重量和首版地图功能 | 主控、屏幕与电池的取舍是否符合产品定位 |
| 2. 比较屏幕样品 | 同一套界面分别运行于 3.5 英寸高亮 IPS 与约 3 英寸反射/半透反射候选屏 | 户外显示方案与实际尺寸 |
| 3. 车把位置阅读测试 | 在计划安装位置、正午阳光、阴影、偏光眼镜条件下查看同一条路线 | 道路、当前位置和数据能否快速识别 |
| 4. 操作测试 | 测试触摸缩放、实体按键、手套和雨水条件 | 用户能否完成记录、暂停、返回等核心操作 |
| 5. 并发性能测试 | GNSS 接收、轨迹写卡、地图切换和界面操作同时运行 | S3 是否满足目标，是否需要升级 P4 |
| 6. 功耗与续航测试 | 使用预定电池/电源测量各状态电流，再做连续运行 | 电池容量、屏幕亮度和续航承诺 |
| 7. 确认供应与结构 | 核对屏幕料号、贴合方案、接口、外壳和批量资料 | 是否可以锁定首版 BOM 并进入小批试产 |

推荐先完成屏幕与功耗比较，再锁定量产料号。本文件中的主控、尺寸与亮度范围用于指导样机验证；尚未取得的样品测量、报价和供货承诺不作为既定事实。
